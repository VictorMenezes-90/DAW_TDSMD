Aplicando CSS3

Podemos aplicar diretamente código CSS in-line: <body style="color: rgb(200,255,200);">

Outro método é aplicando o método Incorporado: 

            
            <head>
                <style>
                    body{
                background-color: rgb(200,255,200);
                }

                    p{
                color: rgb(0,0,0);
                text-align: justify;
                }

                    p#Rodapé{
                color: rgb(0,100,0);
                text-align: justify;
                font-size: 10pt;
                font-weight: 300;
                }

                    code{
                color: rgb(0,175,0);
                }

                    h1, p#Rodapé{
                text-align: center;
                }

                    hr{
                border-color: rgb(0,100,0);
                }
                </style>
            </head>

Nas CSS, podemos usar ID (Único, não pode repetir) ou class (pode ser usada em vários elementos; elemento pode ter várias class atribuidas), para identifica-las no <style> podemos usar: 

                
                <style>
                    #ID ou .class: 

                    #Rodapé{
                        color:rgb(0,100,0);
                    }

                    .Rodapé{
                        background-color: rgb(0,255,0);
                    }

                    h1#Titulo{
                        font-size: 18pt;
                    }

                    #Título, p, #Rodapé{
                        color: rgb(255,0,0);
                    }
                </style>
